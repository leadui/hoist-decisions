02 · The problem

One line of diff.
Weeks to undo.

Muse picks a database, an auth scheme, a hosting platform — mid-task, mid-diff, no pause. Switching later means a migration, a rewrite, or living with it. Big calls deserve a pause.

WITHOUT HOIST

The agent guesses, you discover

Muse drops npm install mongoose into a diff at 2am. Nobody chose MongoDB — it simply happened. Six months later the schema fights you on every feature.

WITH HOIST

The agent pauses, you decide

Muse asks instead: answer here, or decide with Hoist. The session pauses, you walk the options, one commit sends Muse back with your choice.

01 · ONE CANVAS

Every option, full detail, one screen

No second screen to open: each card carries its facts, steps, gains and watch-outs inline. Numbers compare as bars; no invented scores.

02 · TAP TO PICK

The card is the picker

Tap a card and it is chosen — the verdict stamps itself on the canvas. No forms, no extra step between comparing and committing.

03 · INTERRUPT

Paused, not blocked

Muse asks: answer here, or Hoist. Pick Hoist and the browser opens while hoist wait holds the session.

04 · COMMIT

One tap back to chat

Review the set, commit, and your agent resumes with your choices.

05 · GUARD

Records that bite

Later conflicts get blocked with a citation to the record you committed.

04 · Decision records

Decisions you can grep.

Every committed moment lands in docs/decisions/ as a MADR record — human-readable, agent-readable, hook-checkable.

---
status: accepted
date: 2026-10-28
door: one-way
deciders: project owner
confidence: medium
---
# Choose persistence for users and projects: SQLite on the server

> Decision: SQLite on the server. Because it stays boring
  while the project grows. Accepted cost: a migration if you
  outgrow one machine.

## Decision Drivers
- Must survive restarts and concurrent saves (the task)
- No ops team to babysit a server (assumed, not checked)

### Confirmation
- [ ] Confirm the hosting disk persists across deploys
- Hoist flags later changes that conflict with this record.
WHAT THE HOOK SEES

Machine-readable by design

Frontmatter both humans and hooks parse: status: accepted door: one-way confidence: medium

A later conflicting install gets blocked citing 0002-sqlite-persistence.md — the record bites back.

05 · Install

Your database decision, guarded in one command.

Python 3.9+, Muse Code, zero dependencies. The page serves from your machine while Muse drafts every moment over the API.

$git clone https://github.com/leadui/hoist-decisions.git # or: git@github.com:leadui/hoist-decisions.git


$python3 hoist-decisions/hoist.py install /path/to/your/project


$python3 hoist.py serve   # browse moments at http://127.0.0.1:7317
