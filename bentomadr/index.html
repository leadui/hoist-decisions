Decision canvases

One box, many kinds of decision

Each template is a fixed bento layout for one kind of decision. Its compartments are components you can swap for another of the same family, so a vendor choice can show a weighted matrix instead of a fact table without breaking the reading order.

Component library

Nineteen compartments, each with a job

Every component says when to use it, when not to, and the data it needs. Families decide what can swap with what: evidence shows why, verdict states the choice, effects show what follows, plan says how to get there and how to know, context frames it.

Chooser

Which canvas fits your decision?

Pick the kind of decision, then tick the evidence you actually have. The kit picks a template and swaps compartments to match your evidence, never the other way round.

Use it in another project

Two files, no dependencies

Add the stylesheet and the script, describe your decision as plain data, and render a template into any element. It works in a static page, in React (render into a ref), or on a server with toHTML().

Decision data

Every field is optional. A compartment whose data is missing renders hatched, with a prompt saying what to add. Here is the full example behind the build-vs-buy template.
